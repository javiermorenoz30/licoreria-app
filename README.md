# CELICOR La Castellana — App móvil

Aplicación móvil nativa para Android y iOS construida con React Native + Expo y preparada para Supabase.

## Desarrollo

```bash
npm install
npx expo start
```

## Objetivo V1

- Catálogo y búsqueda
- Carrito
- Registro / login
- Delivery o retiro
- Checkout
- Pedidos e historial
- Panel administrativo básico
- Inventario y promociones
- Verificación de mayoría de edad

## Marca
CELICOR La Castellana — Caracas, Venezuela.
